## 2. 场景编译器

编译器读取当前任务必要的正式人物、事件、机制、现实、知情、文风片段、状态和前文，生成自足写作包。至少编译：

- 场景事实与禁止信息；
- 每个人知道/相信/误解/怀疑/不知道/隐瞒；
- 即时目标、信息优先级、风险边界、停止/改目标条件；
- 空间与物体初始状态；
- 关键动作“原因 → 完成 → 结果 → 下一步”；
- 关键对白“谁对谁 → 回应什么 → 已有前提 → 为什么回应”；
- 正文声音模型版本、本场主参考模块与裁剪后的短声音胶囊；
- 叙事决策模型版本，以及按本场触发条件裁剪的 `NARRATIVE_DECISION_CARD`：进入点、详写节点、压缩范围、心理停止条件、高风险叙事接缝、`subject_anchor`（各段主要叙述承载者与允许主语转移点）、`paragraph_entry_anchor`（可继承代词的强连续段首、必须重新点名的重定位及竞争先行词）、`character_surface`（人物当场常态、必须可见的状态偏差、感知者与接收动作；无变化时明确不强加神态）、`prose_function`（本场有效描写/持续气氛、真实转折点及应抑制的无功能装饰）、读者重定位点与收束状态；不得只发送规则编号或预写具体句子；
- 生成侧文风执行摘要：本场必要的段落连续性、阶段完成后进入下一行动时的分段边界、段落负载、心理/判断落点、同义复述控制与场景尾部边界。验证/推理场景必须明确：规律第一次形成时允许必要判断，后续复现只写新增变量、新证据或结论变化，不重复整套结论；修复碎片化时不得仅删除换行，把不同注意对象、多个完成步骤、阶段结论和后续计划盲目并成长段。
- B2 锁定边界：必须守恒的关键事实/证据、认知边界与重要判断形成时机、主要因果、对白前提、关键物体和离开状态；普通动作数量、重复检查和原稿段落不默认锁定。

许可要求：认知无越权、行为有动机、空间可执行、动作现实成立、对白前提完整、未来信息已隔离、无阻塞性 `HARD` 缺口。

## 4. 密封初稿生成与 B2 叙事结构编辑

使用新上下文。初稿生成器实际收到的第一段必须是冻结包内的“密封生成器运行头”，然后才是场景执行状态、项目声音胶囊、文风执行摘要和必要前文。初稿生成器只接收：

- `FROZEN` 写作包；
- 包内裁剪的项目声音胶囊；
- 包内裁剪的本场叙事决策卡；
- 包内文风必要片段；
- 包内或密封附带的必要前文。

不得提供完整工作流、完整人物/单卷/机制文件、有效记录、成熟作品全文或作品名、回归 oracle、失败样本或编译推理。初稿生成器只返回 `package_id + RAW_DRAFT`；发现包内不足时返回 `COMPILE_BLOCKED`。

初稿完成后，**必须使用另一个新的、独立于初稿和验收的上下文**作为 B2 有事实边界的小说叙事结构编辑器，只接收本次完整 `RAW_DRAFT`、对应未改动的 `FROZEN` 包和 `package_id`。RAW_DRAFT 是可重构素材，不是逐句、逐段、逐动作合同；最终稿守恒对象由 FROZEN 的 B2 锁定边界决定。

B2 在内部执行：

1. 从 FROZEN 锁定必须完成/禁止提前完成、必要事实与证据、人物认知上限、重要判断首次成立的相对时机、主要行为因果、关键对白前提、关系/情绪必要变化、关键物体与离开状态；
2. 找出场景真正的叙事发动机，重新决定详写、略写和省略，不按 RAW_DRAFT 的检查步骤平均用力；
3. 在锁定边界内整场重写：允许改变篇幅、段落、叙事焦点和非因果性的局部呈现顺序；允许删除非必要普通动作、无信息增量的重复检查、已经由动作成立后的解释性心理、静态环境陈列和缺少动机的非关键结尾动作。段落合并只适用于同一连续注意或动作阶段，不得仅删除换行，把多个完整叙事节拍粘成一个长段；同段内容也不得只是主题相关的句块并置，必须保持可读接缝；
4. 不得删除支撑关键判断的必要证据，不得颠倒真实时间—因果顺序，不得改变认知上限、把不确定写成确定、把未完成写成完成或新增包外事实；
5. 脱离 RAW_DRAFT 句序，只顺读最终 DRAFT：先标出每段主要叙述承载者与主语序列。同一人物仍在连续感知、行动或思考时，优先保持其显式或承前省略主语；若出现人物、物体、工具、身体部位或环境之间的频繁换轴，每次变化必须对应真实行动权、感知来源、受力反馈、对话主导或任务转移，并由前句引出。随后逐段检查“前段末尾活跃中心 → 本段第一指称”：裸代词/省略主语只有在紧邻前段的同一唯一承载者、连续时空/任务/感知链/互动主导且无竞争先行词时成立，其余段首重新点名。修复主语摆动与指代悬空后，再检查叙事接缝与段落负载：凡真正的主语、注意对象、行动权、叙述方式或局部任务改变处，必须能从成稿辨认继续、反应、打断/抢先、结果—选择、联想回落或明确省略跳转；不能只因前后谈论同一对象就判为连贯，也不能靠批量插入连接词补缝。然后核对 `character_surface`：关系、压力、犹豫、警觉、体面或用力方式发生变化时，成稿须有一项具体可见偏差并被后续回应/动作接收；不得因反对动作标签而把人物表层全部删空，也不得按段补神态。再核对 `prose_function`：每个转折须有真实前后差异，每项环境/物件/感官/姿态描写须承担定位、阻力、反馈、人物状态、关系、判断/动作变化或持续气氛，并被后文接收；删除后这些作用均不受影响的内容应删除、并入动作或重写关系。最后核对详略主次、远距离重复、自然收束，以及关键人物/物体状态、动作可达性、必要证据与离开状态；逐段确认是否仍处于同一对象、压力、时间、空间、任务、行动权与叙述声音形成的持续因果脉冲。若只能通过改变锁定边界才能成立，返回 `EDIT_BLOCKED`。

B2 必须检查 RAW→DRAFT 是否因删冗丢失角色化口语、迟疑、意外回应、关系细节和生活趣味；优先移位/重写/等价替代，而不是将人物磨成标准答案。同时验证影响后续动作的占手/支撑状态，没有必要逐步描写普通拿放。负向增益判断见 `10`。

B2 只输出最终 `package_id + DRAFT`，不输出删改说明或检查表；原初稿不交给盲验器。

### 4.1 完整物理章组装

正式章节和完整正文环境测试的一个或多个 B2 输出先登记为 `SCENE_DRAFT`，不得直接成为整章正文。后续场景只读取前一场景经独立桥接核对后的章内临时状态和必要可见前文；前一场景改变时，直接依赖它的后续包自动 `STALE`。

全部计划场景达到 `SCENE_READY` 后，按[完整章节组装与连续生产](09-完整章节组装与连续生产.md)冻结 `CHAPTER_ASSEMBLY_PACKAGE`，记录章计划、上一 `VALID` 章或卷首 `N/A`、场景顺序与哈希、跨场承接、整章离开状态、目标字数、近期重复窗口及 `CA` 版本。新的独立章节组装器只接收该包、有序 `SCENE_DRAFT` 和上一章必要可见末尾，输出 `chapter_id + CHAPTER_DRAFT`；不得读取 `RAW_DRAFT`、完整仓库、旧短测 Oracle 或验收意见。完整正文环境测试建议目标 5500—7500 个汉字，硬下限 5000；不足时返回章计划重编，不得由组装器注水。

组装器可以删除重复重入/退场、修复章首和跨场过渡、重新分配过渡篇幅，但不得改变场景锁定事实、认知、必要证据、主要因果和离开状态。需要改变锁定边界时返回 `ASSEMBLY_BLOCKED`。

**同一上下文自称完成两遍不等于独立 B2**；当前完整章测试必须实际完成两个隔离生成侧上下文，并另有独立章节组装上下文。控制器另行保留初稿、B2 和 CA 的不同对话标识或可核实的交付顺序凭据；**不得把 RAW_DRAFT 或这些凭据提前提供给盲还原器**。验收比较阶段仅依据可核实记录判定隔离状态为 `VERIFIED / UNVERIFIED / BREACHED`；未提供记录不得自称 `VERIFIED`，但也不得无证据判定 `BREACHED`。不得把旧 Oracle、历史失败正文、验收结果或其派生答案带入 B2/CA。B2 不能代替事实修复；RAW_DRAFT 中若存在与 FROZEN 冲突或无法在锁定边界内整理的问题，应返回 `EDIT_BLOCKED`。

B2 输出门槛（按叙事功能判断，数字仅是触发复核的信号）：
- **段内叙述主轴是独立硬门槛**：每段通常维持一个主要承担感知、动作、心理或关系压力的人物。同一人物的连续动作不得无必要地拆给静物、工具、身体部位和环境等多个句子主语；主语稳定允许承前省略、连续谓语和从属结构，不要求句句重复代词。只有真实的行动权、感知来源、受力反馈、对话主导或任务转移才允许换轴；
- **段首指代落点是独立硬门槛**：每段第一处“他 / 她 / 它”或省略主语必须能由紧邻前段的唯一活跃承载者无回读恢复；场景/小节开头、时空/任务/行动权/对话主导重置、外力插入、回忆回落或竞争先行词出现后，必须重新点名；
- **叙事接缝是独立硬门槛**：相邻句、对白或段落发生主语、注意对象、行动权、叙述方式或局部任务变化时，若正文没有提供可读的继续、反应、打断/抢先、结果—选择、联想回落或明确跳转，必须重写。把相关信息并排、放进同一长段或添加万能连接词均不算修复；
- **人物可见表层是独立硬门槛**：人物状态或关系压力已经改变时，不能只有动作任务、对白信息和后台心理结论而没有任何可观察偏差；偏差须具体并由后续接收。没有状态变化时不强加神态，不以数量、面部词或动作标签多少机械判定；
- **转折/描写功能是独立硬门槛**：转折词必须对应真实前后差异，描写须改变定位、阻力、反馈、人物状态、关系、判断/行动或持续气氛中的至少一项。仅为增加画面、换词复述或制造表面小说感且后文不接收的内容必须删改；
- 同一普通动作/观察/判断链连续出现三个及以上单句段时，除非每段承担不同的停顿、突变或转场功能，否则输出前必须合并或重写；
- 修复上项时不得把“合并”理解为删除段落边界。若一个段落同时塞入多个已经完成的检查、不同对象、阶段结论和下一步计划，且读者需在段内多次重新定位当前在做什么，必须删冗、重排或按真实叙事节拍重新分段；
- 段落级断点为**独立硬门槛**：一处明显应分段的已完成局部阶段与新阶段并置，不能以“总体行动目标未变”“段落不算很长”“减少单句段”或综合观感补偿。先重构、必要时删冗；同一未完成动作及其即时反馈不强制拆分；
- 同一结论已经由动作、观察或一次必要心理判断成立后，后续复现、录像、回看或场景尾部不得再次完整抽象总结，只保留新增变量、新证据、结论变化或由结论导致的选择；
- 规则已进入包但最终 DRAFT 仍违反时，优先审计 B2 是否真正获得了结构编辑权限、写作包是否把非必要过程误锁定、整场信息/判断重复是否仍残留，以及最终稿关键物体位置是否连贯；不继续向人物卡或文风基线堆同义禁令。

## 5. 独立验收器

使用与生成器不同的新上下文。

1. 正式连续正文与完整正文环境测试都只给完整 `CHAPTER_DRAFT` 与章节组装包冻结时确定的上一章读者可见必要末尾（卷首为 `N/A`）。冻结整章盲还原：场景转换、位置、物体、认知、动作触发、对白前提、关系/情绪/目标变化、章节获得及无法确定项。不得给状态快照、后台摘要、场景包或章节组装包。
2. 再给章节组装包、冻结场景单元和验收协议进行比较。旧短测 Oracle 不得提供给新完整章测试。
3. 比较通过后运行事实连续性、因果人物、叙事声音、语言重复四层审计。L1 对物体位置缺口须判断其是否影响行动可达性、证据或连续性：不能把一切省略日常拿放的叙述都当作明确空间跳变；L4 先检查每段主要叙述承载者是否稳定、主语切换是否对应真实行动权/感知/受力转移，再检查段首第一指称是否有紧邻唯一活跃先行词，然后检查人物状态变化是否有被成稿接收的可见表层、相邻叙述接缝、转折/描写功能与独立阶段段界。无功能频繁换轴、悬空或歧义段首代词、人物状态只存在于后台、伪转折、无功能装饰、明显接缝断裂或漏断点均可单独判 FAIL，不得用同一总体目的、高分、主题相关或段落表面顺畅抵消，同时不能按神态数、转折词数、描写数、字数或短句数机械定罪。

验收器不得看到生成过程内部推理；盲还原不得在看到写作包后回填。

### 5.1 独立读者质量门

必须另开读者盲读上下文，只读最终 DRAFT（章可加上一章可见结尾），返回 `READER_PASS / READER_REVISE / READER_FAIL`，同时保存具体阅读兴趣、乏味/过密操作、人物可辨性及详略证据；没有正文定位证据记 `REVIEW_INSUFFICIENT`。事实 PASS 不抵消读者 FAIL；读者审查不得先读包、RAW 或旧评语，更不能把旧失败正文反馈给密封生成器。见 `10`。

## 6. 返修与状态提交

完整正文环境测试一旦在比较阶段判定 `FAIL`，本 attempt 立即结束；不得把比较答案或其派生诊断交给原生成器改到通过。修改负责层后重新编译新包，并使用全新上下文重跑。

正式正文可在同一 `FROZEN` 包下做不改变事实、认知、动作链、对白前提与离开状态的受控语言返修；返修若需要改变这些执行状态，旧包必须 `SUPERSEDED` 并重新编译。

章节通过后按 `PREPARED → COMMITTED` 事务：

- 追加章节状态增量：前后状态版本、本章变化、悬念、关系/认知、物品及后续依赖；
- 更新最新状态快照；
- 同时写入验收记录、物理章映射和运行台账；上述提交全部成功后才将正文标为 `VALID`；
- 每3—5章生成 checkpoint；
- 上位事实进入变更传播，不由正文直接确立。

修改旧章时，从该章增量识别真实依赖，标记受影响章节和写作包待重审/`STALE`。

下一章只能从上一 `VALID/PUBLISHED` 章与已提交快照冻结，不能以 `CHAPTER_DRAFT` 或章内临时状态作为正式输入。

## 7. 严格通过边界

- 回归测试和高风险章节没有独立初稿生成、B2 叙事结构编辑、盲还原验收上下文，不得标为严格正文级通过；多场景正式章节若没有独立章节组装与整章验收上下文，也不得标为 `VALID`。生成侧隔离尚无可核实凭据时，内容判定可单独记录，但严格资格记 `UNVERIFIED`，不得计为严格通过或假称已经证明隔离。
- 初稿生成器或整编器读到 oracle、完整规则库或历史失败样本，本次测试作废。
- 写作包依赖过期，本次生成作废。
- 旧 `VOICE_QUALIFIED`、自由校准、VQ 或 T01—T08 结果既不是启动条件，也不能冒充完整正文环境测试通过；当前组合必须以不少于 5000 汉字的正式剧情完整章、独立双门和作者判断证明。
- 盲还原器在接收完整 `CHAPTER_DRAFT` 前已经看过写作包、比较材料、生成推理或后台资料，本次完整章测试直接 `INVALID`，即使它声称没有主动使用也不能恢复资格。
- 盲还原借写作包补正文未表达的前提，本次验收失败。
- 完整章测试 `FAIL` 后使用验收答案指导原生成器、B2 或 CA 返修，本次后续结果无资格记为严格通过。
